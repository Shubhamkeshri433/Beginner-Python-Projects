## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Shubhamkeshri433/Beginner-Python-Projects.git
```

### 2. Open the project

```bash
cd Beginner-Python-Projects
```

### 3. Run any Python file

```bash
python calculator.py
```

You can run any `.py` file individually.
